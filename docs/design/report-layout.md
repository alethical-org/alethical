# Alethical standalone reports

Load [Alethical document presentation](document-presentation.md) first, alongside the shared
[report-layout skill](https://github.com/euglopi/tool-settings/blob/main/shared/skills/report-layout/SKILL.md).
This guide adds the treatment for standalone research reports, data reports, PDF plans and templates.

- Use the full symbol and wordmark because a standalone report may be read outside Alethical.
  Website posts and their graphics use the approved symbol alone, as defined in
  [design principles](design-principles.md#2-the-green-visual-system).
- Use Letter size and a white page by default. The cover follows the presentation guide; the
  running header carries the part name and the footer the page number. Explicit user background,
  logo or layout choices control.
- Apply the shared report checks to every numeric cell, including 3-digit row numbers: size for
  the widest heading and value in the real font with padding, inspect every page, and make generated
  table checks fail on wrapped or overflowing numbers. Never fix a cell by clipping, shrinking or
  changing its value.

The shared skills own evidence preservation and validation. This guide never supplies another
report's facts or changes a report's approved scope.
