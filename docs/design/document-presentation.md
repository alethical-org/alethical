# Alethical documents for outside readers

Use this guide for Alethical reports, plans, decks, one-pagers, memos and slides. It owns the
Alethical treatment; reusable methods live in the shared
[document-presentation skill](https://github.com/euglopi/tool-settings/blob/main/shared/skills/document-presentation/SKILL.md).
Reports also use [standalone report rules](report-layout.md). The user's explicit background,
logo or layout request controls. Website behavior stays with [design principles](design-principles.md).

## Brand and page treatment

- Default to a white page. Use the supplied
  [white-background wordmark](brand-assets/alethical_wordmark_white_gradient.png) as supplied,
  without cropping, stretching, recoloring or a mismatched background. Use the
  [black-background wordmark](brand-assets/alethical_wordmark_black_gradient.png) only when a black
  background is explicitly requested. A green-logo request is not a black-background request.
- Document palette: accent green `#35C46B` for rules, the section tag, links and our comparison
  column; deep green `#0f7a45` for small labels and links on white; ink `#11150f`; muted `#6b716b`;
  surface `#fbfcfd`; hairline `rgba(17,21,15,0.10)`. These are document values, not new website tokens.
- Libre Franklin for everything a reader reads, every number included, with equal-width digits.
  Never use a monospace or dotted-zero face for numbers. JetBrains Mono is only for short uppercase
  section, stat and callout labels. Space Grotesk is only inside the supplied wordmark image.
- Follow [brand assets and identity](brand-identity.md) for clear space and asset choice.

## Structure

- Cover: wordmark, date, title, 1-line claim, a contents block whose columns show the document's
  parts with page numbers, and who it is for. Nothing else.
- Running header: small wordmark left, current part name right in green small caps. Footer: page
  number only.
- 1 page, 1 idea: a heading that states the claim, 1 lead sentence of at most 2 lines, then evidence.
  No section numbers.
- Use green as lines: a table-header rule, a rule above a stat, or a callout's left bar. A filled
  band appears at most once per document, for the figure the reader must leave with.

## Tables, figures and links

- Table headers use sentence case, the text face, bold and a green rule beneath. Hairline rules
  separate rows. Numbers are right-aligned with equal-width digits and stay on 1 line. The first
  column is bold only when it is the key.
- The example category key uses a filled square for handled, a dot for alone and an outlined square
  for partner. Preserve shape plus color and use only categories the report actually supports.
- Comparison grids place large totals above their columns, ours in green. Stat blocks use a
  small-caps label, big number and 1 muted line explaining it.
- Each figure's caveat is 1 muted line beneath it, retaining the period, mean or floor and source.
  Keep any additional qualification needed for accuracy.
- Cross-references are green links by page.

Preserve facts and inspect every rendered page using the shared method; these project choices
never waive readable numbers, working links or faithful asset proportions.
