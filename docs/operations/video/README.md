# Alethical video work

Alethical owns its editing guides, recipes, production records and small recovery assets in this
repository. Publishing these records does not approve posting an unfinished clip. Keep each
record's editorial holds, uncertainty and recovery limits.

## Guides

- [Short video editing](shorts-guide.md): source, timing, captions, framing, sound, review and recovery.
- [Social writing and posting](../social-publishing.md): Alethical's voice, links, accounts and post records.
- [Article and recording publishing](../blog-publishing.md): website and YouTube requirements.
- [Shared social publishing practice](https://github.com/euglopi/tool-settings/blob/main/shared/guides/social-publishing.md): platform-independent preparation, posting, editing and verification.
- [Shared social video upload limits](https://github.com/euglopi/tool-settings/blob/main/shared/guides/social-video-upload-limits.md): official sources, dates and account-specific limits.

Read the applicable Alethical and shared guides before work. Save each new reusable lesson in its
owning guide before finishing: Alethical-specific guidance here, universal guidance in tool settings.
Update links and affected checks together. Keep 1 owner for each rule; do not duplicate it across repos.

## Storage and recovery

| What | Where |
| --- | --- |
| Guides, recipes, transcripts, captions, exact small assets and licensed fonts | This folder in Git |
| Source recordings, raw audio and finished exports | Local media folder and the authorized team Drive folder; restore access is separate from public repository access |
| File hashes, sizes, media locations and recovery limits | Each event's inventory and restore guide |

Recipes read the local media folder through `ALETHICAL_MEDIA`. The Forward Debate default is
`~/Movies/Alethical/forward-debate-2026`; another event needs its own folder and inventory.
Never store credentials or authentication callbacks in the repository.
