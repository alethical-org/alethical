# Donor-state reference check, 13 September 2026

Net: The full national HUD 2026 Q2 ZIP-to-county file supplies the donor-state
lookup. The held Abeler 2025 sample allocates $38,700 to Minnesota and $1,250 to
unknown, adding back to its $39,950 of Individual-kind cash contributions.

## Source and copy

- Source: [HUD-USPS ZIP Code Crosswalk Data](https://www.huduser.gov/portal/datasets/usps_crosswalk.html).
- Selection after sign-in: `ZIP-COUNTY`, `2nd Quarter 2026`, with no state filter.
- Download: `ZIP-COUNTY_062026.xlsx`, 2,464,671 bytes, 1 worksheet named `Sheet1`.
- Reference date: 2026-06-30. Copy completed: 2026-09-13T12:19:46.695703+00:00.
- SHA-256: `1175d0496ea66ec6a571ce47adb63502ef8485b20e8f1ded635ea0ff351f5627`.
- Actual columns: `zip`, `geoid`, `city`, `state`, `res_ratio`, `bus_ratio`,
  `oth_ratio`, `tot_ratio`. The downloaded county column is named `geoid`,
  whereas HUD's source description names it `COUNTY`.

All 54,570 rows were read. ZIP and GEOID values are stored as text. There are no
empty rows. Of the county codes, 54,561 have 5 digits and 9 have 2 digits.
The import preserves leading zeros in complete reference codes. It never supplies
missing digits in a donor's filed ZIP.

## ZIP outcomes

The 39,484 distinct ZIPs divide into:

| Outcome | ZIPs |
| --- | ---: |
| Assigned to 1 supported state or DC | 39,284 |
| Unsupported jurisdiction | 187 |
| Counties in more than 1 state | 4 |
| Incomplete county code | 9 |
| Total | 39,484 |

All 50 states and DC have assigned ZIPs. The 200 unassigned ZIPs remain present
with null state values. Missing donor ZIPs, malformed donor ZIPs and ZIPs absent
from the reference also produce unknown, without changing the reference count.

The 4 ZIPs crossing state borders are 42223 (Kentucky/Tennessee), 57638
(South Dakota/North Dakota), 65761 (Arkansas/Missouri) and 66053 (Kansas/Missouri).
Neither the preferred mailing state nor a majority of addresses assigns these
ZIPs to an individual donor's state.

The 9 incomplete county rows contain 77352 with GEOID `48`, 96799 with `60`,
96940 with `70`, 96941 through 96944 with `64`, and 96960 and 96970 with `68`.
These are not full county identifiers. They remain unknown rather than being
padded, discarded or filled from the mailing-state column.

## Real sample

The held registration 17868, source year 2025 fixture has 82 Individual-kind
Contribution rows marked cash, with 74 distinct printed names:

| State bucket | Cash payments | Printed names | Cash |
| --- | ---: | ---: | ---: |
| Minnesota | 79 | 71 | $38,700 |
| Other states | 0 | 0 | $0 |
| Unknown | 3 | 3 | $1,250 |
| Total in this fixture | 82 | 74 | $39,950 |

The 3 unknown payments have ZIPs that are only 4 digits after trimming spaces.
The same results are asserted through both committee finance response variants
and the legislator campaign-finance response. The separate empty-reference test
still proves that missing matches cannot become guessed states. These names are
spellings in the file, not proof of 74 different people. Name counts across
state buckets are not generally additive.

## Release and limits

The prepared table is `alethical/api/data/zip_states.json`. It is generated by
`scripts/build_zip_state_reference.py` and travels with the server release. It
does not replace any contribution, expenditure or filing snapshot. A new source
copy goes through the same manual import, review, tests and pull request.

HUD excludes PO-box-only ZIPs and some ZIPs it cannot locate. Applying this dated
lookup to an older gift identifies its filed ZIP using the 2026 Q2 reference;
it does not prove the person's residence at the time. Public responses carry
state amounts and reference metadata, never ZIPs, counties or donor names.

This check supplies source evidence for
[issue 2146](https://github.com/alethical-org/alethical/issues/2146).
The issue's release report records the final automated checks and live responses.
