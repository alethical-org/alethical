# TV ad records guide

TV ad records collect station files from KSTP-TV, KARE and KMSP-TV. They help readers distinguish what was ordered, billed, credited or reported in campaign records. A title alone does not prove an ad aired or a bill was paid. The first reader release is for signed-in administrators. Public access is not approved.

## Where to begin

Administrators can enter from the TV ad records card at `/money` (a grey bar holds its count line's place while the count loads, and the line is left out if the count cannot be read), from its separate group at `/money/search`, or directly at `/money/ads`. A short reading guide lives at `/money/ads/guide`. The guide is not in public article search, sharing controls or the sitemap. Signed-out and ordinary signed-in readers see the existing not-found result for direct TV addresses. Their money pages keep the existing six cards and no TV groups or gaps.

Related records may also appear beside a committee, a legislator's confirmed campaign committee, a candidate, an outside spender, a particular race, or a lobbying principal. Each connection belongs to the exact checked file. A candidate's card lists files with a checked connection to the candidate's confirmed committee first, under "Files with a checked connection to {committee}", then "Station files that name this candidate"; the 2 groups never mix, and a candidate with no confirmed committee shows only the second. Roles read in plain words ("Named on page 2", "Advertiser, as printed"), never as stored codes. On a legislator's money tab the card names the committee and the seat it registered for ("{committee} · registered for House District 99A"), and a row with a checked election connection adds it after the role ("Advertiser, as printed · 2026 general election"). Race connections retain their stage. Search under a printed agency spelling is a name search, not proof that the records describe the same organization.

## Search and browse at `/money/ads`

Administrator search matches held file labels, checked facts and machine-read text, including originals awaiting publication review. Text matches remain labelled Not checked. Browse by station folders, agency names, stations or years. Machine-read agency names are marked Not checked; each exact spelling stays separate. Folder filters cover station, folder year and the literal station category. The Category menu lists All categories, then Federal, State and Local by level of government, then Non-candidate issue ads and Terms, then any other station-supplied name from A to Z; it offers only categories present in the collected records and prints each name as the station wrote it. The newest available folder year is selected in the first response. An explicit All years choice stays in the address and survives a file visit and return. A row on the Years tab opens that year's station folders, and a year row on a station page opens that station's folders for the year. Browser Back and Forward, a copied address, and a link opened in a new tab show the results that address names. Year headings inside an agency's station cards group its files and are not links. Results have 12 rows per page. The count line reads "Showing 1–12 of 214 folders" when there is more than 1 page and "4 agency names" when everything fits on 1 page; capped search reads "Showing 1–12 of more than 500 files" and says when more exist. No results draws no count line. Each search result says what matched: "Matched the file name", "Matched the folder label", "Matched a checked fact" or "Matched the file text, page {n}", with the matching words under it.

A station category describes the station's filing choice. It does not identify an election office or establish a connection. Unknown categories stay unknown. Spelling variations remain separate. A checked empty folder can appear with zero files.

Changing a filter or page keeps the previous results visible with an updating notice until the replacement arrives. A failed request keeps usable results and offers retry. A new search starts at page 1. An empty result explains that there are no matching collected records; it does not mean no ads existed. Counts and source dates load separately, so a failure in one does not hide the other.

On phones the 4 browse tabs stay in one row with an underline under the chosen tab; longer names wrap to 2 lines.

Folder and printed-name screens retain the authorized heading, metadata and results during retries and temporary failures. While replacement results load, retained rows use the existing 85% opacity treatment with an updating status. Before a name has loaded, their headings are “Station folder” and “Printed agency name”. Changing the record or account clears prior content; missing or withdrawn records never retain old details. A folder with no held files says “No files to show in this folder”. A folder page names its station in the line above the heading, and the station name links to the station's page.

Ordinary links between TV records use the running app rather than reloading its scripts. Real addresses, open-in-new-tab behavior, browser Back, and search return context remain available. Changing the record starts a fresh administrator access check and clears the previous record. Folder files and other-file suggestions use a stable filename order, with file identity breaking ties.

## What counts mean

- Station files held counts station plus FCC file ID once when original contents have been saved.
- Unique file contents counts different saved byte sequences, including older versions. Identical contents count once across files.
- Files with an approved copy counts a file once when any saved version still has an approved viewable copy.
- Files whose text could not be fully read uses the current text reader and latest successfully downloaded contents.
- Files we couldn't download from the FCC uses each file's latest conclusive download attempt, including never-saved files.

These counts overlap. They are not ad counts, spending totals or proof of complete history. Folder-list failures count folders separately. Missing values never become zero. Sources name the newest known upload, last successful listing check and last successful file copy separately for each station.

## Read a saved file

At `/money/ads/files/<key>`, the station, filename, folder year and station category identify the file. The header links the file's folder and each printed agency name's own page; a machine-read agency name is marked Not checked beside its link. Administrators can open original page images and machine-read text without publication approval. An available approved copy remains separately identified. Checked facts, dates and connections retain their own evidence and status. The Checked card prints each kind's label once, with every value of that kind listed under it. An election connection prints its year, stage and seat ("2026 general election · House District 99A") and links to the race page when the check also established the campaign-money contest; otherwise it prints the checked office without a link. A connection's role reads with its evidence page as a link ("Advertiser, as printed on page 1", "Named on page 1"). Open a fact's page link to see its quoted evidence. Page controls and phone zoom help inspect an image. Machine-read text begins closed below computer width and remains labelled Not checked. It sits in its own white panel and follows the printed layout the text reader kept: values of one block start at one position, figure columns line up on their right edge under their headings, wide tables scroll sideways inside the panel on phones, sentences broken across printed lines are joined, choices keep one mark column, form fields stack one per row, and runs of underscores show as a blank line. A search term is marked where it appears, including across a printed label and its value such as “Agency name: Sample”. The words, their order, case and signs never change, and nothing is rearranged by meaning; text without a repeated printed structure stays a plain line in source order.

Opening an original does not approve it. Originals say “Original station file · Not checked or approved for publication”. Exact links to metadata-only publication copies retain their not-ready state. A failed image can be retried. An unreadable text page does not imply an unavailable image. Personal contact details are removed before approved publication images and text are generated; a browser overlay is not the redaction. In an approved copy's machine-read text, "Name withheld" appears as a grey chip in the site's own type, and "[Blanked]" in the reviewed text appears as a blank grey box that a screen reader announces as "Blanked". A held original's text is the station's own words and is never marked this way. When the newest approved copy is open and a newer saved version has no approved copy, the page says "A newer saved version has no approved copy yet: its original opens from the versions menu"; every saved version in that menu can be opened.

Saved versions are ordered by first saved time in Central time. The current source follows the latest successful download, so a source changing A to B and then back to A makes A current. Checks never transfer to replacement contents. Links to evidence preserve both source version and exact approved copy. Older approved records stay identified when the current source changes. An exact withdrawn publication-copy link shows its withdrawal state instead of falling through to another copy. Administrators may separately inspect the held original without restoring its approval.

Dollar figures omit cents without rounding; quotations preserve source precision. Gross, net, commission, credits, ordered amounts and reported expenses are separate. Multiple airing periods stay separate. The screens never add documents or versions into spending totals.

## Follow connections and history

Each checked connection has its own quote, page and check date. A folder relationship says only that the folder relates to a committee; files require separate checks. Related documents open the exact checked copy. Expense evidence opens the exact saved campaign-finance row. A changed current filing is labelled without replacing the older evidence.

Agency addresses need a separately checked agency association and preserve the printed role. Identical printed addresses appear once, listing every file that prints them; a role shared by every printing is stated once, and differing roles stay beside each file. The agency page links campaign payments under the exact printed name for both paid-to views: "Campaign payments with this exact printed name" and "Outside spending payments with this exact printed name". Each file row names its folder. Equal names alone do not qualify. Facts may have correction history when each older value remains safe to publish. Withdrawing unsafe information removes the value and quote, including previously approved history.

## Review at `/admin/political-ads`

Administrators reach `/admin/political-ads` through “Review TV ad records” in the existing administrator menu on phone, tablet and desktop.

The private review queue lists source files and retained folders. Select a source version, inspect original pages privately, prepare safe metadata and page text, and mark redaction rectangles. A prepared preview shows the pixels readers would receive. Inspect every page before approving the exact prepared fingerprint and the privacy, metadata and text attestations. Preparation does not approve publication.

Facts require a supported field, value, source page and exact quote. Connections require an inspected target and exact evidence. Correctness and publication permission are separate decisions. Candidate connections require the election stage and named/advertiser/payer role. A race needs its exact contest; adding a campaign-money office and district requires a separate association check. Review cannot promote a folder relationship to its files.

Source or target changes clear earlier review attestations. Saving and retry controls keep their positions and prevent repeat submissions. Failed operations report the failure and allow correction. Withdrawal takes effect on later reader and image requests; old links do not restore approval. Review actions remain in private audit history. Account or sign-in identity deletion removes the reviewer’s account identifier while retaining the source evidence and decisions, including older campaign-payment review history; [user-data-retention-policy.md §6](user-data-retention-policy.md#6-what-deletion-should-mean) owns that policy.

## Sources, privacy and limits

The source archive and operational limits are documented in [fcc-political-files.md](../implementation/fcc-political-files.md). FCC political files must be retained for at least 2 years; older available files are not complete history. There is no coverage of other stations, cable, radio, streaming or online advertising.

Reader requests send search and filter choices to Alethical. Private responses are not cached for shared reuse. Original page pixels may be reused inside the server process under a 32 MiB / 128-page bound, keyed by immutable content hash and page number. Every image request still checks current administrator access and the exact retained source before that reuse. Approved publication images and withdrawal decisions do not use this original-page cache. Administrator permission is checked on every API request. Original documents and review notes remain private. Administrator TV search can match held originals; private review notes do not enter search. No feature here submits an ad request, contacts a campaign, changes a filed expense, or subscribes a reader to messages.

## Visual layout and review

The TV screens use the approved flat background, shared search and menu controls, and neutral document-kind labels. Search occupies at most 780 pixels on larger screens. Folder file rows and station year rows each have one whole-row link, including a visible keyboard outline. Phone folder rows show the document kind below the filename and retain separate airing, upload and version details.

Printed-agency station cards and checked-address cards use 2 columns at computer width and 1 below 1100 pixels. Station and year headings apply to their contained file rows; upload dates remain beside each file. A long filename may wrap without hiding its date or checking status. Address evidence links retain the exact file version, copy and source page.

Station pages show the 3 held counts, then the last successful file copy date and the station's FCC link. Station folders counts folders that hold saved records, the same unit as the Stations tab and the years table; FCC folder pages we listed but hold nothing from (year, office and empty folders) count only toward Folders we couldn't list when their listing failed. The years table lists folders by station category (Federal, State, Local, Non-candidate issue ads, Terms, Not identified, then any other station category name from A to Z) and files per year. A category with no held folder in any year is left out of the table and named once in a note under it ("No Local or Terms folders are held"); a single cell with no held folder says "None held", never a bare zero, because holding no folder does not prove the station has none. Source gaps list files whose text could not be fully read, files we couldn't download and folders we couldn't list, one row each. Below 768 pixels, each year becomes one card with category labels beside their counts.

One shared “Admins only” marker serves the `/money` card, every TV page, connection cards and the `/money/search` group. It centres its own text, so a host's line height or alignment cannot crowd it against a border; a browser check measures the clear space around its text in each host at all 3 widths.

Visual acceptance compares rendered computer, tablet and phone screens with Claude Design's drawings and saved standards. It includes open menus, keyboard focus, pointer hover, disabled controls, loading, failures and empty records. Browser checks separately exercise whole-row links, menu selection, page images, text, saved versions and failure recovery; screenshots do not establish working behavior. Publication statuses and private administrator access remain separate.

File, agency and station loading or failure states keep their identifying heading. Empty agency and station lists use a white message surface. A metadata-only exact publication link can show that its copy is not ready; ordinary administrator archive links still open the original. Saved-version menus stay within the viewport, retain keyboard and touch selection, and show saved time, station upload date and status on separate lines.

Whole-row folder and station links show one keyboard outline around the row, without a second outline around the title. Hover fills the row; pointer clicks do not add a keyboard-only outline. Other-file cards stack title, kind and station upload date at every width.

Final review refinements: address evidence links keep a 44px target while their
keyboard outline follows the link width. Agency row outlines sit 2px inside an
8px corner radius, with 12px horizontal content padding. Empty file and address
surfaces span the available width. An agency with no checked addresses uses the same white empty
surface as its missing file list. Station and file failures name the affected
record and explain “This is a problem on our side” beside the retry action.
