DECISIONS

How "what changed" is carried

Per bill — a change block, not a badge. A soft green panel inside the card: a mono "MOVED MAR 19" line and one plain sentence naming what happened. It reads as a dated report, not an alert. When a bill has moved, the card's separate "Latest action" row is removed — it was the same fact stated twice.
Page level — one dated sentence under the count, in the register of the signed-in home ("2 of the 4 bills you're tracking moved since your last visit on Mar 12").
Ordering — grouped, moved first, with only one divider. The moved group carries no header: the dated summary sentence above already says how many moved and since when, and each card states its own "MOVED <date>" — a third restatement was redundant. The only divider is the grey mono NO CHANGE (no count) marking where the unchanged bills begin, which is what implies the group above it. Grouping was chosen over a sort control because it needs no interaction, explains itself, and collapses to a plain unlabeled list when nothing has moved. Most recent change first within the moved group.
Nothing moved names the fact and stays useful: it dates the last change instead of implying the page is empty. No group headers in this state — one list, no ceremony.
First visit says plainly that there is no "since" yet, and what will happen from now on.
A change with no date keeps the same shape. The eyebrow stays first and stays green — it just becomes MOVED · DATE NOT RECORDED, with the qualifier in grey so "MOVED" still leads and the absence recedes. We kept eyebrow-first rather than leading with the sentence: in a list where dated and undated blocks sit together, one composition is what lets the eye read them as the same thing. Saying the date is not recorded (instead of just "MOVED") also explains the gap, so it reads as the record's silence rather than our omission. Considered and rejected: a trailing sentence like "The record does not date this step" — more words, repeated per card, for the same fact.
A card with no written summary holds fine. Number, title, status and progress, then the green change block — the block simply moves up where the summary was, with 20px of air below the title. Nothing else shifts, and the change actually reads more prominently. Note: the phone card never showed a summary, so on phone the no-summary case is indistinguishable from any other — this composition question is web-only.
Omnibus and hot-issue labels coexist with the change block. OMNIBUS is the ghosted amber chip (transparent, border #e3c17f, text #a76a1a) sitting next to the filled amber code badge — ghosted is what keeps the two apart in the same context. "🔥 Hot issue" is the neutral pill (#f1f1f4) and never amber, because it is an editorial flag, not a code. On web it sits to the LEFT of the Track button with a 16px gap; on phone both labels join the code badge in the top row, which wraps. SF 1832 in this mock carries both at once — the crowded case — and neither competes with the green change block below.
Several changes since your last visit — the normal case while the Legislature sits. The block leads with the most recent change as its sentence, then a quiet dated count of the rest ("2 earlier steps since your last visit →") that opens the bill's full history. One sentence alone would imply nothing else happened.
Phone gains the tracked control — the shared ✓ Tracked button (black #11150f, white text, 44px minimum) in each card's top row, next to the code badge. Black is reserved for Track alone; pressing it again untracks — the same flip both surfaces already use, with no separate untrack treatment.
DECLINED · AND OUT OF SCOPE
No filter control. A watchlist is self-curated and short — people track a handful of bills, not hundreds — and the moved/no-change grouping already answers the only question the page is asked ("did anything happen?"). A filter rail would add chrome to a page whose entire value is being glanceable. If a list ever does grow long, search is the right instrument, not a filter.
No vote tallies in the change block. The tracked-bills data carries every action and its date but no vote counts, so the sentence says "Passed the House and was referred to Senate Judiciary" — never "108–21". Numbers live on the bill's votes, one tap away.
New subhead. "Anything that moves in the official record shows up here" replaces "The bills you're following, in one place. Tap Track on any bill to add or remove it." The instruction is dropped on purpose: the ✓ Tracked button is now on every card on both surfaces, so telling people to tap it labels something already visible, and the empty state still explains how to add a first bill.
