# Sign-in visual history

The `sign-in.dc.html` file and `shipped/` screenshots show the Google-only sign-in that shipped
in August 2026. They are kept as visual history, not as instructions for current work.

The current product behavior, wording, safety rules, and live service settings are in
[`sign-in-guide.md`](../../product-onboarding/sign-in-guide.md). The current build adds email
and password beside Google, confirmation and reset pages, and a signed-in password action.

Do not rebuild from the old HTML file. It does not contain email and password states.
